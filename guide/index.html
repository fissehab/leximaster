Install LexiMaster

LexiMaster is a free English vocabulary app. It installs straight from the browser on a phone, tablet or computer: no app store, no sign-up, and it works offline.

Install guide (PDF) Slides (PowerPoint) Open LexiMaster
  • iPhone, iPad: open the app in Safari, tap Share, then Add to Home Screen.
  • Android: open it in Chrome, tap Install (or ⋮ → Install app).
  • Mac, Windows: open it in Chrome or Edge, click the install icon in the address bar.

Open the link in Chrome or Safari, not inside Facebook or another app's browser: those can't install.
